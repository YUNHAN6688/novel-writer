# NovelStudio · 小说写作工作室 v3.0

基于 **Python + Flask + pywebview** 开发的本地小说写作桌面工具。数据本地存储、无需联网，可打包为独立 EXE 运行，以本地原生窗口打开（不依赖浏览器跳转）。

> v3.0 重大更新：新增剧本转换、拆书分析、AI 提示词生成、图片识别四大模块，关系图谱支持 2D/3D 切换，大纲结构规范化为每本小说独立大纲。

---

## 功能特性

### 📝 写作核心
- 目录树管理小说结构：小说 → 卷 → 章 → 拍，层级清晰
- **每本小说独立大纲**，新建小说自动创建大纲，大纲下可管理角色、地点、势力、道具、事件、伏笔等设定实体
- 右键菜单：新建 / 重命名 / 删除 / 分屏打开节点
- Ctrl/Shift 多选，支持批量删除
- 双击节点编辑正文，工具栏设置字号、颜色、加粗
- 拖拽排序，节点可拖出分屏对照编辑
- 上传图片自定义界面背景
- 导出为 Markdown / TXT
- 日间 / 夜间 / 护眼三种界面模式，界面模式与界面设置统一归入设置

### 🕸️ 关系图谱
- 人物关系可视化，支持 **2D / 3D 两种模式**切换
- 节点拖拽、缩放、悬停查看详情
- 故事线与人物关系树状图展示
- 支持从写作数据自动导入角色和关系

### 🛠️ 故事工作台
- 骨架树：卷 → 章 → 拍 三级结构，点击章节管理拍
- 拍卡片编辑：场景、人物、动作、对话、情绪、伏笔
- 设定档案：角色、地点、势力、道具、事件、资源、概念、伏笔、事实、规则
- 实体关联：正文中使用 `[[实体名]]` 建立关联

### 🎬 剧本转换
- 小说正文一键转换为标准剧本格式
- **两种剧本模板**：
  - 📝 **居中格式**（传统剧本）：角色名居中，对话缩进，情绪提示居中
  - 📋 **靠左格式**（短剧/拍摄剧本）：角色名靠左后接冒号，动作提示在括号中，场景标题高亮
- 支持 AI 智能转换与快速规则转换两种模式
- 支持从小说选择章节或导入外部 TXT 转换
- 拖拽导入 + 路径导入两种方式
- 复制 / 导出 TXT，两种模板输出对应纯文本格式

### 📖 拆书分析
- 导入 TXT 文本自动拆章（支持自定义分章正则）
- 拆分结果可直接创建为新小说
- **八维度拆文分析**：
  1. 🏗️ **结构骨架**：按结构功能分组，标注章节范围与作用，起承转合分析
  2. 📖 **剧情概括**：按大事件分章，核心内容与事件类型，起承转合直接标注章节作用
  3. 👤 **人物分析**：人物详细分析（性格、出场、关系推断），去除冗余出场人物标签
  4. 🪝 **开篇钩子**：前300字分析，钩子类型识别，章末钩子摘录
  5. ⚡ **叙事节奏**：句式节奏分布，快慢节奏判断，优化建议
  6. 💫 **情绪人设**：核心情绪分布，**人设塑造手法分析附原文举例**（对话/微习惯/神态/动作）
  7. ✍️ **行文文笔**：对话占比，金句摘录，文笔特征识别
  8. ✨ **写法借鉴**：可复用写法总结，附原文举例，落地用法建议
- AI 智能拆解与模板拆解两种模式

### 🎨 AI 提示词生成
- **AI 漫剧提示词**：小说转换为 AI 视频/漫剧分镜提示词，包含画面描述、镜头语言、台词、风格参考、负面提示
- **AI 漫画/图片提示词**：小说转换为 AI 图片生成提示词，支持日漫/国漫/写实/油画/水彩五种风格
- **⚡ 一句话生成提示词**：输入一句话描述，AI 自动扩展为完整分镜/画面提示词，支持回车快捷生成
- 漫剧与漫画提示词分开存储，数据库独立区分
- 保存 / 加载 / 复制 / 导出 TXT

### 🔍 图片识别
- 本地图片 OCR 文字识别
- **画面内容描述**：识别人物动作、神态、环境氛围，不只是文字
- 支持全部识别 / 仅文字 / 仅画面三种模式
- 识别结果可复制导出

## 环境要求

- Python 3.10+
- 依赖：`Flask`、`pywebview`
- Windows 需安装 WebView2 运行时（Win10/11 一般自带）
- AI 功能需自行配置大模型接口（base_url / api_key / model）

---

## 运行

```bash
pip install flask pywebview
python novel_app.py
```

或直接运行打包产物 `dist/NovelStudio/NovelStudio.exe`。

---

## 打包为 EXE

```bash
pyinstaller NovelStudio.spec
```

输出位于 `dist/NovelStudio/`（onedir 文件夹形态，稳定性更好）。

## 目录结构

```
novel_app.py        # 桌面窗口入口（pywebview 拉起本地窗口）
app.py              # Flask 后端（数据存取、AI 接口代理）
static/
  index.html        # 主界面（八大功能视图）
  style.css         # 全局样式
  app.js            # 写作核心逻辑（树、编辑器、设置、大纲）
  graph.js          # 关系图谱（2D/3D）
  workbench.js      # 故事工作台
  script.js         # 剧本转换
  split.js          # 拆书分析
  comic.js          # AI 漫剧提示词
  comic_image.js    # AI 漫画/图片提示词
  ocr.js            # 图片识别
assets/             # 图标等资源
NovelStudio.spec    # PyInstaller 打包配置
novel_data.json     # 本地数据文件（自动生成）
settings.json       # 用户设置（自动生成）
```
